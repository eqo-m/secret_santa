# Photos

Drop one photo per person here, named to match their `photoFile` in
`data/people.json` (e.g. `alice.jpg`). These are committed to the repo —
keep them reasonably sized (a few hundred KB each is plenty; the reveal
page displays them small).

`npm run draw` copies each person's assignee's photo into `site/` when
generating reveal pages, so the file must exist here before you run a draw.
